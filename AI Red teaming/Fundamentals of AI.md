## Spam Filtering 

Spam filtering is the process of automatically detecting and separating unwanted, harmful, or junk messages from legitimate communication </br>
Example:
```
Routing emails about "free lottery prizes" directly to the spam folder.
Blocking phishing messages that pretend to be from your bank.
Hiding automated bot comments on social media posts.
```

## Sentiment analysis (opinion mining)

Sentiment analysis (also called opinion mining) is the process of identifying the emotional tone behind a body of text. </br>
Example:
```
Tracking customer reviews to see if people like a new smartphone.
Monitoring social media to gauge public reaction to a movie release.
Analyzing customer service chats to flag angry users for immediate help.
```

Q2: What dimensionality reduction technique transforms high-dimensional data into a lower-dimensional representation while preserving as much original information as possible, and is widely used for feature extraction, data visualization, and noise reduction?

Principal Component Analysis (PCA) is the dimensionality reduction technique that transforms high-dimensional data while preserving maximum variance.

Key Applications

```
Feature Extraction: It combines highly correlated variables into a smaller set of uncorrelated components. </br>
Data Visualization: It projects complex, multi-dimensional data down to 2D or 3D plots for easy viewing.</br>
Noise Reduction: It eliminates low-variance components, which often represent random noise rather than real patterns.</br>
```
