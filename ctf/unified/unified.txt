 JNDI (Java Naming and Directory Interface) is a Java API (Application Programming Interface), not a function or library in the traditional sense. It provides a way for Java applications to interact with naming and directory services, such as LDAP (Lightweight Directory Access Protocol) servers, DNS (Domain Name System) servers, and others.
    
 ldap://10.10.14.19/whatever: This part specifies the LDAP (Lightweight Directory Access Protocol) URL to be looked up using JNDI. In this case, it's trying to connect to an LDAP server located at 10.10.14.19 and querying the resource named whatever.
 The default port that LDAP runs on is port 389 .
