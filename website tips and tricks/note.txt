CSP (Content Security Policy)
-------------------------------
CSP allows website administrators to define and enforce a set of rules that dictate which sources of content can be considered trustworthy and should be executed or displayed by the browser.

CSP can be seen in the Response header 
e.g. Content-Security-Policy:script-src 'self' https://cdn.jsdelivr.net ;

script-src 'self' https://cdn.jsdelivr.net directive allows JavaScript to be executed from both the same origin (the domain of the web page) and the specified CDN domain (https://cdn.jsdelivr.net). 

Can also check CSP rules in CSP Evaluator(https://csp-evaluator.withgoogle.com/)
